PII Leak Scanner

Before publishing, committing or sharing, scan for embedded phone numbers, ID numbers, bank card numbers and email addresses, as well as access keys, private keys, JWTs, tokens of various kinds and credentialed connection strings. Reports the hit type, position, severity and a masked sample; raw values are never echoed back.

How to install

Skill packages follow the open Agent Skills standard (one directory plus a SKILL.md). No request or licence is needed. Pick whichever path matches your client, then just describe the task in chat to trigger it.

① Import the package

Recommended

Download the skill zip and load it from your client's "import / upload local skill package" entry. If SKILL.md sits at the top level of the archive, the package is well formed.

Download packageCurrent version v1.0.0

② Command line

For command-line clients that support the Agent Skills standard: one command syncs the skill into your local skills directory.

$npx skills add m9ai/m9ai-skills --skill pii-leak-scanner-skill

Pass -a to name the client (claude-code, codex); omit it and you will be asked which one to use.

③ Unzip manually

You can also unzip the archive straight into your client's skills directory - no installer to run. The zip is self-contained and can be distributed offline, which makes it easy to host on an internal file server for company-wide rollout.

WorkBuddySettings → Skills directory (as shown in the client)

Claude Code (project level).claude/skills/

Other clients supporting the Agent Skills standard work the same way: drop the skill directory into their skills folder.
